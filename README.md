# BaioHack

BaioHack is a calm health companion marketing site built with TanStack Start, React, and Tailwind CSS.

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run preview
```

## Environment

| Variable        | Description                                                                                            |
| --------------- | ------------------------------------------------------------------------------------------------------ |
| `VITE_SITE_URL` | Production site URL used for canonical links and Open Graph metadata (default: `https://baiohack.com`) |

## Project structure

- `src/routes/` — file-based pages
- `src/components/baiohack/` — site layout and sections
- `src/data/` — content, navigation, and SEO configuration
- `public/` — static assets, `robots.txt`, and `sitemap.xml`
